# Usage

- Abra o UnoArduSim
Inicie o simulador e observe os elementos principais: a placa Arduino virtual, interruptores (que simulam entradas) e LEDs (que mostram o resultado).
- Configure os interruptores
Cada grupo de 4 interruptores representa um número binário (de 0 a 15). Você pode ligar e desligar os interruptores para formar diferentes valores.
- Inicie a simulação
Após configurar os valores de entrada, clique em “Run” para ver o sistema funcionando. Os LEDs vão mostrar o resultado da soma dos quatro números inseridos.
- Observe o resultado
O simulador mostra apenas os 4 bits menos significativos da soma. Isso significa que, se o resultado for maior que 15, ele será cortado (como se tivesse “transbordado”).
- Experimente diferentes combinações
Teste somas simples e mais complexas para entender como o sistema reage. Isso ajuda a visualizar como o Arduino interpreta sinais digitais.
