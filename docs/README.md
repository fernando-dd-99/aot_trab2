# 💾 Simulador de HD Binário com Arduino Uno

Este projeto demonstra, de forma simples e interativa, como o Arduino Uno pode ser utilizado para ler e somar dados binários, simulando o funcionamento de um pequeno HD digital. Utilizamos o software **UnoArduSim** para facilitar a visualização e compreensão do processo.

## 📚 Visão Geral

O sistema simula a leitura e soma de números binários usando o Arduino Uno, representando como dados são processados digitalmente. Ele serve como ferramenta didática para entender lógica binária e funcionamento básico de circuitos digitais.

## ⚙️ Requisitos para Rodar o Simulador

O projeto utiliza o software **UnoArduSim**, um simulador gratuito voltado para testes e aprendizado com placas Arduino (principalmente o modelo Uno). Para rodar o sistema corretamente, é importante verificar os seguintes requisitos:

- 💻 **Sistema Operacional**: Compatível com **Windows** (Windows 7, 8, 10 e 11). Não há versões oficiais para macOS ou Linux.
- 🧠 **Memória RAM**: Recomenda-se pelo menos **2 GB** de RAM para garantir fluidez na simulação.
- 🖥️ **Processador**: Qualquer processador moderno (Intel ou AMD) com suporte a aplicações de 32 ou 64 bits.
- 📦 **Espaço em Disco**: O programa é leve — menos de **50 MB** após instalado.
- 🧰 **Dependências**: Nenhuma instalação adicional é necessária. O executável roda diretamente após o download e extração.

O UnoArduSim é ideal para quem quer testar códigos Arduino sem precisar montar o circuito físico. Ele simula entradas e saídas digitais, LEDs, motores, sensores e muito mais.

## 🕹️ Uso

Esse hardware foi desenvolvido com uma finalidade educacional: ajudar estudantes e entusiastas a entenderem como sistemas digitais manipulam dados binários. Ele simula, de forma visual e interativa, o funcionamento básico de um armazenamento digital — como um HD — usando o Arduino Uno.

Feito com ❤️ para fins educacionais e experimentação com hardware digital.
