# Installation

Para rodar o simulador, siga os passos abaixo:
- Baixe o arquivo compactado disponível neste repositório.
- Descompacte o arquivo em uma pasta de sua preferência.
- Instale o programa UnoArduSim (instruções podem variar conforme o sistema operacional).
- Execute o simulador e carregue o código fornecido para iniciar a simulação.
