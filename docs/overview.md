# Overview
Este projeto demonstra, de maneira simples, como o Arduino Uno pode realizar a leitura e a soma de dados binários com o auxílio do software UnoArduSim.
A proposta é mostrar, de forma visual e interativa, como um sistema pode guardar e manipular informações em binário — parecido com o funcionamento de um pequeno HD digital.

O que o sistema faz?
- Lê quatro números binários de 4 bits (nibbles) através dos pinos digitais do Arduino.
- Soma esses valores e gera um resultado de 4 bits (com possível bit de transporte).
- Exibe o resultado em LEDs conectados aos pinos de saída.
